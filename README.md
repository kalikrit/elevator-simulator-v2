# Elevator Simulator v2

Симулятор работы 4 лифтов в 25-этажном доме с двумя алгоритмами управления.

## Стек

- Vue 3 + TypeScript + Vite
- Vitest для тестов
- Без backend, всё в браузере

## Архитектура

Три слоя с односторонними зависимостями:

- `src/domain/` — чистая логика, ноль зависимостей от Vue
- `src/composables/` — мост между доменом и Vue
- `src/components/` — UI

## Запуск

\`\`\`bash
npm install
npm run dev
\`\`\`

## Тесты

\`\`\`bash
npm run test
\`\`\`
